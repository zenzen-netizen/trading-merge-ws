# Thesis Layer

Isi folder ini:
- reasoning inti strategi
- translasi dari evidence menjadi doctrine
- mapping dari backtest menjadi thesis Meridian

File utama:
- `setup-notes.md` = thesis konseptual umum
- `meridian-thesis.md` = mapping thesis ke workflow Meridian

Pakai folder ini kalau tujuanmu:
- mengingat kenapa strategi ini ada
- menguji apakah tuning baru masih setia ke thesis
- memahami logika sebelum ubah config
