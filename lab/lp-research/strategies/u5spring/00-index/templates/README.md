# U5Spring Templates Pack

Folder ini berisi template pendamping untuk workflow eksperimen yang sering berulang.

Gunakan urutan ini:
1. baca `../experiment-guide.md`
2. isi `../experiment-template.md` atau `experiment-brief.md`
3. jalankan riset di `../../01-research/chart-backtests/`
4. isi `comparison-note.md`
5. kalau hasil cukup kuat, isi `thesis-addendum.md`

Isi folder:
- `experiment-brief.md` = brief eksperimen generik siap isi
- `comparison-note.md` = template compare baseline vs eksperimen
- `thesis-addendum.md` = template addendum saat hasil eksperimen layak memengaruhi thesis

Catatan:
- template ini membantu agent tidak kehilangan arah
- template ini tidak menggantikan baseline canonical
- template ini tidak berarti semua eksperimen otomatis boleh naik ke operator/Meridian/payload
